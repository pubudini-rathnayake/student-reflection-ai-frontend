# 🌸 Student Reflection AI

> An anime-themed AI-powered student reflection and mood tracking web application built with React and Tailwind CSS.

---

## ✨ Overview

Student Reflection AI is a modern, aesthetic web app designed to help students reflect on their daily experiences, track mood patterns, and monitor productivity.

The project combines a clean anime-inspired UI with interactive features to promote self-awareness, emotional reflection, and burnout prevention.

---

## 🎯 Features

- 🧠 Daily reflection input system  
- 😊 Mood selection tracking  
- ⭐ Productivity rating system  
- 💾 Dynamic saving of reflections (React state-based)  
- 🪄 Anime-themed UI with glassmorphism design  
- 🎨 Gradient-based aesthetic interface  
- 📱 Responsive design (mobile-friendly)  
- ⚡ Fast frontend using Vite  

---

## 🛠️ Tech Stack

- ⚛️ React (Frontend framework)  
- 🎨 Tailwind CSS (Styling)  
- ⚡ Vite (Build tool)  
- 🧩 JavaScript (Logic)  
- 🎯 Lucide Icons (UI icons)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/student-reflection-ai-frontend.git
```

### 2. Navigate to the project folder

```bash
cd student-reflection-ai-frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

### 5. Open in browser

```plaintext
http://localhost:5173
```
